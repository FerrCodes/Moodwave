# 🌊 Moodwave

**Moodwave** adalah aplikasi web jurnal harian berbasis suasana hati dan musik.  
Pengguna dapat mencatat perasaan mereka dan mengaitkannya dengan satu lagu yang mewakili hari itu.

> Proyek ini dibuat sebagai bagian dari LSP Teknologi Digital.
> © 2026 Feri Ferdianto XII PPLG 3 - SMKN 5 Malang

---

## 🚀 Fitur Utama

- 🔐 **Login & Register** (menggunakan Laravel Breeze)
- 📅 **Dashboard Kalender Mood** – lihat sekilas suasana hati dalam seminggu
- ✍️ **Tambah Catatan** – pilih mood, tulis cerita, dan tambahkan judul lagu + artis
- 🎵 **Arsip Soundtrack** – daftar semua lagu yang pernah dicatat, lengkap dengan filter mood
- 👤 **Profil & Playlist Favorit** – tampilkan 3 lagu terakhir sebagai playlist pribadi

## 🛠️ Tech Stack

| **Lapisan** | **Teknologi** |
|:---|:---|
| Backend | Laravel 11 (PHP 8.1+) |
| Frontend | Blade + Tailwind CSS (inline styling) |
| Database | MySQL |
| Autentikasi | Laravel Breeze |
| Version Control | Git & GitHub |
